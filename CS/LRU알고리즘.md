## 페이지 교체 알고리즘

메모리 꽉 찼을 때 어떤 페이지를 스왑 영역으로 내보낼지 결정하는 알고리즘

- 간단한 알고리즘
  - 무작위: 무작위로 대상 페이지 선정 후 스왑 영역으로 보낸다.
  - FIFO: 처음 메모리에 올라온 페이지를 스왑 영역으로 보낸다.

- 이론적 알고리즘
  - 최적: 미래의 접근 패턴 보고 대상 페이지 선정 후 스왑 영역으로 보낸다.
 
- 최적 근접 알고리즘
  - LRU: 시간적으로 멀리 떨어진 페이지를 스왑 영역으로 보낸다.
  - LFU: 사용 빈도가 적은 페이지를 스왑 영역으로 보낸다.
  - NUR: 최근 사용한 적이 없는 페이지를 스왑 영역으로 보낸다.
  - FIFO 변형: FIFO 변형하여 성능을 높인다.
